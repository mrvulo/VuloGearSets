# Kurztest im Spiel

Nach größeren Änderungen. Neue Dateien oder `.tga`: WoW komplett neu starten, sonst `/reload`.

1. Einloggen (und einmal `/reload`), Charakterfenster: Set-Leiste mit Texten auf „Anlegen“ und
   „Speichern“, Statuspunkte hinter den Setnamen.
2. Set anlegen, speichern, umbenennen, Symbol ändern, per Ziehen umsortieren, löschen.
3. Rechtsklick-Menü eines Sets und Auswahllisten in `/vgs` liegen vorne, direkt unter der Liste.
   Jede der sechs Seiten in `/vgs` einmal öffnen: kein abgeschnittener Text, kein Lua-Fehler.
4. Über einen Ausrüstungsslot fahren: Flyout mit passenden Teilen.
5. Händler und Taschen: Tooltip eines Set-Teils zeigt „Sets: …“ und flackert nicht.
6. Forever: Set erscheint auch in Blizzards Ausrüstungsmanager.
7. Kein Lua-Fehler in der ganzen Runde.
